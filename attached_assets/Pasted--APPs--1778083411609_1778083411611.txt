مطلوب إجراء تحديث وتطوير شامل على جميع التطبيقات (APPs) الحالية داخل المنصة وربطها ببعضها ضمن منظومة تشغيل موحدة خاصة بوحدة عمليات المراكز والوكلاء، بحيث يتم توحيد قواعد البيانات والواجهات والتقارير والصلاحيات وربط جميع التطبيقات بلوحة تحكم مركزية موحدة.

التعديلات المطلوبة:

1. تعديل أنواع النشاط داخل جميع النماذج والتطبيقات لتشمل:

* وكيل رئيسي
* وكيل فرعي
* مركز خدمات
* نقطة بيع ثابتة
* سيارة بيع وخدمات متنقلة
* بائع متجول

2. تعديل هيكل البيانات بحيث يدعم:

* التبعية الإدارية
* المنطقة
* المدينة
* نوع القناة
* حالة النشاط
* الخدمات المتاحة
* المسؤول المباشر

3. إضافة قسم خاص بالخدمات المقدمة داخل كل نقطة أو وكيل، مع إمكانية اختيار:

* 4G
* FWA
* ADSL
* FTTH
* eSIM
* FIXD VoLTE
* Recharge Services

4. تطوير قسم “إمكانية السوق والمعاملات” ليشمل:

* عدد عمليات التفعيل اليومية
* عدد عمليات التجديد
* حجم المبيعات الشهرية
* عدد العملاء اليومي
* مستوى الطلب على كل خدمة
* تقييم الموقع التجاري
* وجود منافسين مباشرين

5. إضافة قسم جديد باسم:
   “التقييم التشغيلي”

يشمل:

* الالتزام بساعات العمل
* توفر المواد والمخزون
* جودة خدمة العملاء
* الالتزام بالتسعيرة
* سرعة تنفيذ الخدمات
* النظافة والترتيب
* الالتزام بالهوية البصرية

6. تطوير نظام التقييم النهائي ليكون ديناميكيًا حسب نوع القناة:

* الوكلاء
* المراكز
* السيارات المتنقلة
* نقاط البيع
* الباعة المتجولين

بحيث تختلف معايير التقييم والأوزان حسب نوع النشاط.

7. إضافة Dashboard مركزية وربط مباشر بالتقارير بحيث تدعم:

* استخراج PDF
* إرسال التقارير عبر البريد الإلكتروني
* إرسال التقارير عبر WhatsApp
* إرسال تقارير نصية مختصرة
* Excel
* CSV
* تقارير تحليلية
* إحصائيات الأداء
* مقارنة المناطق والقنوات
* مؤشرات KPI Dashboard

8. دعم كامل للغة العربية داخل جميع التطبيقات والمخرجات والتقارير وقواعد البيانات مع:

* UTF-8 Encoding
* RTL Support
* منع تشوه النصوص العربية
* دعم الخطوط العربية
* توافق كامل مع PDF والطباعة
* دعم اللغة العربية داخل الإشعارات والرسائل والتقارير

9. تطوير قسم الصور والمرفقات ليشمل:

* صور خارجية
* صور داخلية
* صور الأجهزة
* صور الهوية البصرية
* صور المخالفات
* إمكانية رفع فيديو قصير عند الحاجة

10. إضافة نظام ملاحظات وقرارات تفتيش يشمل:

* ملاحظات المفتش
* مستوى الخطورة
* توصيات المعالجة
* مهلة التصحيح
* حالة المتابعة
* إعادة الزيارة
* سجل كامل للزيارات السابقة

11. دعم النظام للعمل على:

* الهواتف
* الأجهزة اللوحية
* الويب

مع تحسين:

* سرعة الأداء
* سهولة الاستخدام
* سرعة البحث
* استقرار النظام
* تجربة المستخدم

12. المطلوب أن تكون جميع النماذج والتقارير وقواعد البيانات قابلة للتوسع مستقبلًا دون الحاجة لإعادة بناء النظام، مع دعم:

* تعدد التطبيقات
* الربط بين التطبيقات
* الصلاحيات الديناميكية
* API Integration
* التحديثات المستقبلية
* التوسع الجغرافي والتشغيلي

13. مطلوب ربط جميع التطبيقات الحالية ضمن منصة موحدة بحيث تتم مزامنة:

* المستخدمين
* الوكلاء
* نقاط البيع
* التقارير
* الزيارات التفتيشية
* الخدمات
* الإحصائيات

بشكل لحظي Real-Time بين جميع التطبيقات ولوحات التحكم.
