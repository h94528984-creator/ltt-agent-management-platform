========================
NEW MODULE: INSPECTION SALES LOG
========================

Add a new module called "Inspection Sales Log" specifically designed for the Inspection Team to record, validate, and analyze sales performance observed during field visits.

========================
1. PURPOSE
========================
- Enable inspection team to capture real on-ground sales data
- Compare actual sales vs reported system sales
- Detect discrepancies and fraud
- Provide sales insights during inspections

========================
2. ACCESS
========================
- Inspection Team (create/edit logs)
- Agent Affairs (review logs)
- Indirect Sales Manager (analyze performance)
- Head of Unit (full visibility)

========================
3. DATA MODEL
========================
Create a table: inspection_sales_logs

Fields:
- id
- agent_id (relation)
- inspector_id
- visit_id (linked to inspection report)
- date
- location (auto geo or manual)
- products_sold:
    - recharge_cards (quantity + value)
    - devices (type + quantity)
    - services (FTTH / ADSL / SIM / etc.)
- observed_daily_sales_value
- reported_sales_value (from system/manual entry)
- variance (auto-calculated)
- notes
- attachments (images, invoices)
- compliance_flag (OK / Suspicious / Violation)

========================
4. FEATURES
========================

A. Smart Entry Form (Mobile First)
- Easy input during field visits
- Dropdown for products
- Auto-calculate totals
- Voice-to-text for notes (optional)

B. Variance Detection Engine
- Automatically calculate:
    variance = observed - reported
- Highlight discrepancies:
    - Green: Normal
    - Yellow: Warning
    - Red: Critical

C. Integration with Inspection Reports
- Each inspection report can include:
    - Sales Log section
    - Linked data

D. Sales Validation Dashboard
- Compare:
    - System sales vs field sales
- Detect:
    - Under-reporting
    - Over-reporting
- Rank agents based on accuracy

E. Agent Sales Credibility Score
- New KPI:
    credibility_score = based on variance history
- Show trend over time

========================
5. DASHBOARD WIDGETS
========================
Add to main dashboard:

- "Field Sales vs Reported Sales"
- "Top Agents with Variance"
- "High Risk Agents"
- "Inspection Coverage vs Sales Volume"

========================
6. ALERT SYSTEM
========================
Trigger alerts when:
- High variance detected
- Repeated discrepancies
- Suspicious behavior patterns

========================
7. REPORTING
========================
- Export:
    - Excel
    - PDF
- Filter by:
    - Region
    - Inspector
    - Agent
    - Date range

========================
8. ADVANCED FEATURE (IMPORTANT)
========================
- AI Insight:
    - Detect patterns of manipulation
    - Predict high-risk agents

========================

Goal:
Transform inspection team into a data-driven control layer that improves sales transparency, reduces fraud, and enhances decision-making.
