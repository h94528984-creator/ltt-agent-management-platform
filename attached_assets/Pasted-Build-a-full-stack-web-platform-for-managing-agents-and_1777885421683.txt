Build a full-stack web platform for managing agents and service centers for a telecom company (Libya Telecom & Technology - LTT), specifically for the Retail Sales Department – Western Region.

The platform should be modular, scalable, role-based, and optimized for operational efficiency, reporting, and governance.

========================
1. CORE SYSTEM ARCHITECTURE
========================
- Frontend: React (Next.js preferred)
- Backend: Node.js (Express or NestJS)
- Database: PostgreSQL
- Authentication: JWT + Role-Based Access Control (RBAC)
- Dashboard UI: Clean, modern, KPI-driven (similar to ERP/CRM systems)
- Language: Arabic (RTL support) + English optional
- Deployment-ready (Replit + Docker optional)

========================
2. USER ROLES & PERMISSIONS
========================
Define hierarchical roles with permissions:

1. Head of Unit (Super Admin)
- Full control over system
- Approve decisions, policies, reports
- Crisis management dashboard
- Track all operations

2. Indirect Sales Manager
- Manage agent sales
- Monitor e-recharge and equipment sales
- Access performance dashboards
- Generate reports

3. Agent Affairs Team
- Manage contracts and compliance
- Track violations and inspections
- Approve/terminate agents
- Workflow-based recommendations

4. Inspection Team (Field Operations)
- Mobile-friendly interface
- Submit inspection reports with:
  - Photos
  - Violations
  - Geo-location
- Schedule visits
- Send reports to Agent Affairs

5. E-Charge Sales Officer
- Issue recharge invoices
- Track recharge cards (serials, balances)
- Coordinate with IT systems

6. Technical Support & Training
- Ticketing system
- Agent training tracking
- System issues resolution

7. Centers Support & Reconciliation
- Integrate with Double Click system (mock API)
- Reconciliation dashboard
- Track mismatches and settlements

8. Airport Sales Point Team
- POS interface
- Daily sales tracking
- Attendance tracking
- Report issues to supervisor

9. Warehouse Manager
- Inventory management:
  - Devices
  - Recharge cards
- Stock movement logs
- Alerts for low stock
